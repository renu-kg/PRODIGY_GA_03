# 🧠 Text Generation with Markov Chains  

A simple **text generation project** built during my **Generative AI Internship at Prodigy InfoTech**.  
This Python script uses **Markov Chains** to learn word patterns from a given text and generate new, creative sentences that mimic the writing style of the source material.  

---

## 📋 Overview  

Markov Chains are statistical models that predict the next word (or character) in a sequence based on the previous one(s).  
In this project, I trained the model using *Romeo and Juliet* to generate new “Shakespeare-like” lines 🎭.  

Watching code produce poetry was honestly magical! 💫  

---

## ⚙️ How It Works  

1. **Reads a text file** (`my_text.txt`)  
2. **Builds a probabilistic model** using the `markovify` library  
3. **Generates random sentences** based on learned text patterns
